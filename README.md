# PDF alati

Spajanje, razdvajanje, rotiranje, brisanje i premještanje stranica PDF-a.

**Stranica:** https://app-bonic.github.io/pdf-alati/

## Privatnost
Alat radi u potpunosti u pregledniku. Ništa od onoga što upišeš ili učitaš ne šalje se na poslužitelj, nema kolačića ni analitike — pogodno za rad s osobnim podacima (GDPR). Sve biblioteke su u mapi `lib/`, pa stranica ne kontaktira ni vanjske CDN-ove.

Dio zbirke [app-bonic alati](https://app-bonic.github.io/alati/).
